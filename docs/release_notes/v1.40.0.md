## Core

### Token-based pagination

Several Scaleway APIs (Audit Trail, Autoscaling, ...) paginate with an opaque `next_page_token` cursor instead of page numbers, which the SDK's list-all helpers could not follow, leaving users to page by hand. The client now detects token-based responses and keeps requesting pages with the `page_token` query parameter until the token runs out, transparently aggregating results.

For manual paging, responses expose the `UnsafeNextPageToken()` method, which returns the token to pass to the next request, or `nil` on the last page.

```go
// ListAll-style helpers now work on token-paginated APIs:
req := &audit_trail.ListEventsRequest{PageSize: 100}
res, err := api.ListEvents(req) // aggregates all pages behind the scenes

// Manual paging:
resp, err := api.ListEventsPage(req) // single page
token := resp.UnsafeNextPageToken()    // nil on the last page
```

[#3545](https://github.com/scaleway/scaleway-sdk-go/pull/3545), [commit 7e4e743](https://github.com/scaleway/scaleway-sdk-go/commit/7e4e74307d3eab1a0a0ce2a87f6647f7162a4250) and [#3534](https://github.com/scaleway/scaleway-sdk-go/pull/3534), [commit 52f7f99](https://github.com/scaleway/scaleway-sdk-go/commit/52f7f99a32a2298bd032772a4d00ef95aa8138e3)

### Money helpers

Money amounts returned by APIs are split into `Units` and `Nanos` fields, which made arithmetic and comparisons awkward. Two new helpers convert back and forth with a single integer nanosecond value:

```go
m := scw.NewMoneyFromNanos(15_500_000_000, "EUR") // €15.50
nanos := scw.MoneyToNanos(m)                      // 15500000000
```

[#3516](https://github.com/scaleway/scaleway-sdk-go/pull/3516), [commit 46763ab](https://github.com/scaleway/scaleway-sdk-go/commit/46763ab9fc78781eca1af94bd3a83750d3a2068f)

### JSON Schema tags on config types

The config file types now carry `jsonschema` tags, so tools can generate an accurate JSON Schema of the Scaleway config file format — handy for editor completion and validation of `~/.config/scw/config.yaml`.

[#3510](https://github.com/scaleway/scaleway-sdk-go/pull/3510), [commit 0408d20](https://github.com/scaleway/scaleway-sdk-go/commit/0408d203173ded878657e9bd4fb0af93d08e317e)

## File

### Filesystem creation from snapshot

Filesystems no longer have to be created empty: `CreateFileSystem` accepts `FromSnapshot` with the source snapshot ID, so a filesystem can start with the snapshot's data already in place.

```go
fs, err := fileAPI.CreateFileSystem(&file.CreateFileSystemRequest{
    Region: scw.RegionFrPar,
    Name:   "restored-fs",
    FromSnapshot: &file.CreateFileSystemRequestFromSnapshot{
        SnapshotID: snapshotID,
    },
})
```

[#3578](https://github.com/scaleway/scaleway-sdk-go/pull/3578), [commit bd5114c](https://github.com/scaleway/scaleway-sdk-go/commit/bd5114c3537056bdad2a45b2243d0c31c830e32f)

### Nullable snapshot size

[#3553](https://github.com/scaleway/scaleway-sdk-go/pull/3553), [commit a960e37](https://github.com/scaleway/scaleway-sdk-go/commit/a960e37debfcc6e62b16029e5cec55378415244f)

    // ...
